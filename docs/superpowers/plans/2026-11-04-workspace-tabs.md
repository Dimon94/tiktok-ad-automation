# 工作台多页面标签

用户已确认按前一轮提出的标签行为实施。复用 shadcn Tabs 与 TanStack Router，不更换框架。

- URL 路径标识页面，查询条件保存在对应标签；重复点击菜单恢复已有标签的 URL。
- 采用 React Activity 保留页面状态并停用隐藏页面 Effects。每个标签使用独立内存路由保存匹配与查询条件，导航及离页守卫转交主路由，避免所有 Outlet 跟随当前 URL 切换。
- 隐藏页面DOM及浮层随容器缓存，避免固定输入ID冲突与残留遮罩；本地传输及提交中继续使用原有守卫。
- 标签关闭释放页面，最后一个标签不可关闭；活动标签关闭后选相邻标签。
- 未保存表单切换标签不丢失；关闭、离开租户/BC 或刷新仍保护未保存内容。
- 用户、租户、BC、角色变化重置标签；不持久化表单及业务数据到浏览器存储。
- 验证菜单去重、URL/历史、表单与筛选保留、关闭释放、作用域隔离、移动端布局及生产/体验版构建。
