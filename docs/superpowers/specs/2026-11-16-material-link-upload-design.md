# 素材链接批量上传设计（已确认）

## 目标与入口

在素材库增加“素材链接上传”按钮。用户在多行文本框中每行粘贴一个 TikTok Creative Studio 预览链接，选择当前 BC 下有写权限的广告账户后提交。支持多选，每条有效链接上传到每个所选账户。提交前显示有效链接数、重复项、无效行和目标上传任务数。

## 实现方式

采用现有素材库内的独立链接上传批次，复用后台任务调度、账户授权、官方 TikTok 通道、素材查询和预览能力。现有文件导入依赖原件和分片，不把外部 VID 伪装成本地文件；链接批次保留自己的来源和状态，并将核实后的账户素材纳入素材库详情。独立页面或浏览器逐条直传会割裂现有队列与详情，不采用。

## 输入与命名

- 解析明确支持的预览域名及唯一 vid 参数，不抓取任意网页，不把网页地址作为视频下载地址。
- 空行忽略，重复 VID 首次保留并提示，错误保留原行号供修改。提交前必须消除无效行。
- 默认使用提交时上海日期、源 VID、原输入顺序编号命名：`YYYYMMDD_VID_001.mp4`。日期和顺序在批次建立后固定，重试不重新编号。
- 请求有幂等标识，重复提交同一原请求不会另建上传批次；刷新后从批次历史恢复查看。

## 执行与结果

后台按链接与账户建立独立任务，冻结租户、BC、连接绑定及账户范围，执行前再检查授权。使用官方 `UPLOAD_BY_VIDEO_ID`，不默认转换素材字节。保持平台调用限流及并发准入，浏览器离开后继续执行。

保留源 VID、原链接、请求文件名、平台实际文件名、目标账户、返回 MID/VID、执行阶段与错误。上传回执只表示已提交；根据 MID 或精确命名查询实际账户 VID，再回读核验。不得假设源 VID 等于入库 VID，不得仅按查询总数判断成功。

相同内容可能被平台合并：保留每条来源与同一实际素材的映射，显示“与第 N 条为相同素材”，不反复改名或制造副本。平台名与请求名不一致时在详情如实展示。超时与未知结果先核实原请求，不能盲目重传；明确失败允许单条重试，重试保持原目标。

## 列表、详情与预览

上传队列可查看链接批次、总量及逐条进度，状态区分排队、上传中、已提交待核实、成功、相同素材、失败与结果未知。详情展示每个账户的实际上传位置、MID/VID、命名和错误。

成功条目支持“预览账户素材”，按明确账户与实际 VID 调用现有账户视频预览能力，点击时获取临时地址，过期可重新获取。此批次详情及账户素材记录可从素材库重新打开。本轮预览范围为上传结果对应的账户素材，不新增整个广告账户的远端素材浏览器。

## 边界与验证

复用当前导入开关与成员角色控制，保持租户、BC、账户隔离，禁止使用开发机个人 MCP 凭据代替产品用户授权。根据代码实现补充审查后的数据库迁移；不部署、不执行真实上传，除非用户另有具体授权。

行为测试覆盖解析与顺序、账户授权、幂等、持久任务恢复、实际 VID 变化、内容合并、未知结果核实及预览隔离。并发/锁测试使用真实 PostgreSQL 与 Redis；外部 TikTok 仅在传输边界替身测试。前端验证粘贴、校验、账户选择、进度、详情、预览和刷新恢复，并完成类型检查与构建。
