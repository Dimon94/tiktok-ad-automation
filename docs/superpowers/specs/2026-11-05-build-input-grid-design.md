# 广告搭建录入改造（用户已确认第二版原型）

## 目标与方案

主页面保留每行一个剧名和每行一个账户的快速粘贴。明确显示“素材类型”视频/图片单选。版权方、应用、策略紧凑排列；取链参数默认摘要、按需展开，缺必要参数直接提示；策略摘要合并在配置区。删除全部剧目覆盖账户及 BC 授权说明。

曾考虑主页面全宽表格、粘贴列映射。用户选择简单文本输入配合大弹窗，降低常规操作负担。入口固定为“填写更多剧目信息”。

## 详细信息弹窗

顺序：剧目名称（必填）、素材标识（选填）、推广链接、剧目 ID（选填）、归因名称。支持逐格编辑、单列/矩形 Tab 粘贴、自动加行、撤销、清空和键盘移动。确认整体更新剧目和信息；取消不修改主表。保留文本编号前导零。空行忽略、缺剧名/重复剧目/错误链接/超限定位行列，不静默错位。

主页面账户直接粘贴，保留原账户选择入口。底部固定操作栏显示输入数量、保存草稿、下一步：准备链接与素材。

## 业务语义

- 自动取链支持的已接入版权方，链接留空时自动获取；其他版权方需手动提供。ID 留空自动查询真实版权方编号；手动链接无 ID 时生成本地编号。
- 网眼手动链接必须提供归因名称；自动取链读取版权方返回值。其他版权方按现有规则。
- 非空素材标识替代剧名，按文件名包含匹配、忽略大小写、去首尾空格、按字面文本处理；零结果不回退剧名。视频、图片统一。
- 标识不依赖手动链接，必须随草稿保存、恢复和重新准备。单行补链不得清除已有素材标识。保持租户/BC 权限及分页边界。

## 实现范围

复用现有输入行 JSON 持久化补充信息（现有 API 字段 manual_links/manual_link 扩展支持无 URL 的辅助字段，是否手动取链仅以非空 URL 判断），不新增数据库列。读取标识以草稿当前输入行为准，图片候选将匹配依据冻结入快照。现有历史输入无标识自然按剧名匹配，无额外回退分支。开发不执行真实广告或版权方操作、不部署、不推送。
