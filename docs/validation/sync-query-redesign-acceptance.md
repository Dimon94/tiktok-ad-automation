## 实施决策

1. 保留规范事实及现有月分区、账户/业务日期身份，不因“量大”盲目拆分业务事实或增加素材类型到事实主键。类型纠正仍覆盖原事实，不能双算金额。
2. 新增规范 scope、合并需求、到期头、执行子桶，统一目录/报表/余额调度；冻结观察时间、需求代数、owner 和租约代数各自承担不同职责。
3. HTTP 期间释放业务事务。返回后重新锁定并核验执行/授权围栏，平台调用失败和本地额度拒绝区分记录；readiness不消耗平台额度，真正发送只有一套准入。
4. 窄目录当前投影、素材当前引用、广告组日与素材日派生模型承接查询；事实发布和 dirty 标记同事务。成员/顺序/summary 是 T0，页面指标可更新并明确水位。未派生显示 BUILDING，不把缺失当零。
5. 日/月分区创建离开业务发布事务，缺分区暂写 DEFAULT，由独立短事务维护。发布仍原子替换，不以中途分批提交换取假性能。
6. 全停旧消费者后迁移，保留旧任务 ID、冻结路由、页与游标；旧有效租约未过期则 defer，不强行接管。不部署长期双调度兼容层。
7. 暂存清理保留未完成子桶、有效租约和未结算成本保护。V2同步消息明确7天有效期，退役后7天压缩正文、30天回收身份；终态摘要90天后经对象存储全文校验及持久提交凭证归档。旧合同消息不冒用新TTL。平台小时金额属于原始事实，停止原30天自动删除；快照和暂存仍可按合同清理。生命周期独立审查所见缺口已修复并通过本地定向回归；真实对象存储与24小时归档服务率尚未验收。
