# 素材链接上传本地验收

范围：用户已确认将 VID 链接批量上传加入素材库。仅本地实现；没有推送、部署、生产迁移或真实 TikTok 写入。最初提供的 30 条星屿链接未在本轮开发中执行上传。

## 已实现

- 素材库新增「素材链接上传」与链接批次历史。每行粘贴一个已知 TikTok 预览链接，提取 VID、校验、去重并保留原行号；支持当前 BC 的多个可上传广告账户。
- 使用上海日期生成 `YYYYMMDD_源VID_原行号.mp4`。单批最多 500 个非空链接、20 个账户、2000 条账户任务。任一目标无权时整批拒绝，不部分受理。
- 官方 SDK JSON `UPLOAD_BY_VIDEO_ID`；复用现有 `materials.upload_video_url` 准入额度（同一物理视频上传端点），无新增配额或开关。退役 MCP 通道明确不支持新增 VID 写入；不使用开发机个人凭据。
- 持久批次、事务 outbox、逐项领取租约与发送围栏、周期恢复扫描；相同请求 UUID 原样重放幂等，变更内容拒绝。未知结果只核实，明确未发送/无副作用失败才可重新上传。
- 上传后按 MID、账户 VID 或稳定名称查回并读详情登记。只返回 VID 时先读一次，查空再搜索名称；名称多页查完后判断唯一性，跨页多候选交人工核实。
- 平台合并内容时保留全部来源，按账户 MID 复用本地素材映射。展示请求名、平台实际名、源 VID、实际账户 VID/MID、错误与请求标识；成功后可预览明确账户的实际素材，临时 URL 不持久化。BC/登录切换取消旧预览。
- 素材目录显示链接导入的实际账户来源，详情可跳回原批次。

## 验证

真实本地 PostgreSQL 隔离库 `tkada_link_upload_test`，Redis 应用 DB14/测试 DB15；外部服务替身在 SDK 的 HTTP 传输边界，没有真实广告 API 请求。

- 链接行为、VID SDK 合同及既有上传适配器：56 passed（排除退役 MCP 用例）。覆盖解析、顺序、原始行号、多账户去重、全部目标预授权、并发创建幂等、并发领取、重复投递、崩溃恢复、未知不重传、撤权、VID 变化、平台合并、明确失败重试、无 MID 回执及跨页唯一/歧义。
- 既有来源上传、账户预览、租户素材读取与读取 API：47 passed。
- 新增链接浏览器用例 4/4 passed；完整素材浏览器回归 29 passed / 4 failed。失败为已有 3 个布局色值断言与 BC 切换保留搜索断言；在独立目录检出提交前 HEAD 后，4 项均同样失败，未修改公共样式或公共 BC 导航。最终链接/查看者/账户预览定向回归 6 passed。
- TypeScript、正式版 Vite、演示版 Vite 构建通过；修改范围 Biome、Ruff 与新模块/SDK 的 ty 检查通过。
- 隔离库执行 0132→0131→0132 迁移往返成功。迁移包含批次、条目、发送围栏、分页候选、租约、索引及租户/BC/账户复合来源约束。
- 测试清理沿用既有 automation_rule_evidence / automation_rule_run 循环外键 SAWarning，未将其报告为无警告。
- 全量 demo:coverage 检查仍有 58 个既有接口未覆盖（AI 工作台/经营统计等）；本次 6 个新增操作均有演示处理器。客户端生成差异只保留本功能合同，避免混入历史接口同步。演示数据是本地合成，不代表平台联调。

复核修复：无 MID 回执回读及查空回退、跨页名称歧义；补充测试均通过。仓库同时存在其他工作流未提交改动，本轮只暂存素材链接相关文件。
