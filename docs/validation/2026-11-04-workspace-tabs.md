# 2026-11-04 工作台多页面标签

## 行为与实现

- 复用已安装的 shadcn Tabs，菜单导航打开标签，相同路径不重复打开，菜单恢复该标签查询参数。支持标签关闭、相邻回落、键盘切换和 Delete 关闭；最后一个标签保留。
- 主 TanStack Router 负责 URL、鉴权、导航及历史；每个标签以独立内存路由保存匹配及搜索参数。React Activity 保存表单、分页、筛选状态并断开隐藏页面 Effects。
- 缓存页面的 DOM 在隐藏时移出当前文档，避免表单固定 ID 冲突。Dialog、Sheet、Select、DropdownMenu、Tooltip 使用页面 Portal 容器，避免旧遮罩覆盖当前页面；页外导航继续使用默认 Portal。
- 已有表单守卫登记未保存内容，切换标签保留输入；关闭标签、离开作用域、刷新仍保护编辑内容，包括隐藏标签。上传中的本地传输继续使用原有离页守卫，策略及管理表单的提交中状态不静默暂停。
- 用户、租户、BC、角色变化清理缓存。刷新仅恢复当前 URL，不把未提交表单或业务数据持久化到浏览器。无新增依赖、后端、数据库或广告写入。
