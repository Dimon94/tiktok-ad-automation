# 搭建页紧凑布局还原

用户指出生产实现比已确认第二版原型松散、侧栏过宽。原因是上一轮只接入新表单，仍沿用工作台18rem侧栏、inset外框、卡片lg上下24px、独立步骤卡片及7xl正文宽度限制；没有把原型的整体比例一起落实。

## 修正

- 桌面侧栏288px→194px，保留图标折叠/移动抽屉；去除inset外框与额外圆角阴影，让正文从导航边缘自然展开。
- 压缩顶栏、标签条及正文外边距；保留现有多页面标签交互，不隐藏导航或上下文。
- 搭建步骤改为一行圆点进度，不再单独占大卡片。正文取消7xl限制，宽屏右侧不留固定大块空白。
- 素材类型保持明确单选，与标签同排；版权方/应用/策略采用紧凑字段间距。取链参数与策略摘要仍可修改/查看详情，错误提示不隐藏。
- 只覆盖搭建表单卡片的留白、圆角和阴影，不改其它业务卡片默认值。录入区保留可调高度，操作栏压至必要高度；剧目表格弹窗与业务规则不变。

- 114项页面回归通过：workspace-shell、build-preparation、build-link-config，覆盖194px导航、桌面/图标/手机导航切换、标签守卫、表格弹窗、取链参数及草稿行为。
- 新增1440px/1920px布局边界：侧栏194px；闭合配置区≤230px、步骤条≤26px、操作栏≤70px；正文右侧空白≤24px，主按钮首屏可见。390px无整页横向溢出。均实际运行通过。
