## 具体修改

原head已过期、转移或正在被锁时，即时交接返回False；仍提交末页，沿既有规范恢复重新领取发布资格。读取发生在数据库事务外；新增head行锁只持有到末页与outbox提交，不跨网络或Celery排队持数据库锁。发布继续原run/gen/owner/route、目录发布锁及完整性围栏；旧读取消息在terminal_staged处停止，重复消息不重复读平台。

发布复用原代成本账本，新producer只记录零HTTP，不重复计数。配置的目录窗口40及Worker并发不变；既有发布消费者不重新要求head覆盖完整执行期限，240秒grant不保证覆盖排队与210秒发布，不把配置窗口声称为所有过期恢复状态下的数学硬上限。
