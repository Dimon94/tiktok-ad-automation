## 最小变更与围栏

单账户refresh_report_directory取得原BC键shared，再取同租户/BC/账户键exclusive；读取pending/facts前拿齐，两把锁均持至事务结束。不同账户热报可并行，同户仍互斥。默认refresh_account_directory、健康检查和多账户报告始终原BC exclusive，保留健康轮转多户时的锁顺序。旧版本BC exclusive与新shared互斥，因此滚动更新没有去重保护空窗。每事务只执行一次单户热报规划；禁止同事务先shared再升级exclusive。最初将异常拆户当作普通执行路径，后续已撤回该判断：普通热报大多数仍多账户，health始终默认exclusive。
